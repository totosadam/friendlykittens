To preview
  Open index.html in any browser. All links work offline.

To publish
  Upload everything in this folder to your host's public folder,
  keeping the same structure (photos/ stays a subfolder).

  To swap one out, save the new photo over the file of the same
  name and re-upload it. Nothing else changes.

A note on the kittens page
  It deliberately does NOT list individual kittens by name. It
  shows your photos and asks people to call for current
  availability, so nothing on the site can go stale or promise a
  kitten that is already reserved. If you would rather list this
  week's litter properly, send the names, colours, sex, status
  and a photo for each and it can be built as real listings.
